# KPML FinApp Dashboard

A polished mobile customer dashboard concept for KPML FinApp, designed to match the brand direction from the provided KPML logo: emerald green as the primary brand color, gold and bronze accents, and a professional microfinance look.

## Included
- Mobile-first dashboard layout optimized for Android-sized screens
- KPI summary card, quick actions, finance overview, progress tracking, transactions, profile, and bottom navigation
- Offline banner and loading/empty-state styling
- Brand-led color system informed by the KPML logo reference

## Run locally
Open `index.html` in a web browser.

## Notes
The provided logo was used as a design reference for the palette and brand direction. The repository includes a stylized badge asset for layout previewing. For production use, replace `assets/logo-badge.svg` with the exact official logo asset provided by the brand team.

## Files
- `index.html` – Dashboard layout
- `styles.css` – Visual design system and layout styling
- `assets/logo-badge.svg` – Brand badge placeholder rooted in the supplied logo reference

This design is ready to be translated into a Flutter UI implementation for Firebase-backed app development.
